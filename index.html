a7III Monitor — kömək

Android telefonla (USB kabel)

  1. Səhifəni telefonda Chrome ilə, https:// ilə başlayan ünvandan açın. Fayl kimi açanda birbaşa USB işləmir. iPhone-da bu yol yoxdur.
  2. Kamerada: MENU → Setup → USB Connection → PC Remote. Menyuda USB Power Supply varsa, Off edin, yoxsa kamera telefonun batareyasından şarj olur.
  3. Kameranı USB-C OTG kabeli və ya adapteri ilə telefona qoşun və yandırın.
  4. Mənbə siyahısında Sony a7III · USB kabel seçin, Qoş basın, açılan siyahıdan kameranı seçin, Android icazə istəyəndə razılaşın.

Bu yolda görüntü kameranın canlı görüntüsüdür: Full HD deyil, bir az gecikmə ola bilər. Ekspozisiya və kadr üçün kifayətdir. İcazə bir dəfə verilir, sonra kabeli taxanda özü qoşulur.

Kompüterdə (Imaging Edge Webcam)

  1. Sony-nin rəsmi saytından pulsuz Imaging Edge Webcam proqramını quraşdırın, sonra kompüteri yenidən başladın.
  2. Kamerada: MENU → Setup → USB Connection → PC Remote
  3. Kamerada: MENU → Camera Settings2 → Live View Display → Setting Effect ON — belə olmasa, ekspozisiyanı dəyişəndə görüntü və skoplar dəyişməz.
  4. Kameranı USB kabellə qoşun (USB-C portu tövsiyə olunur) və yandırın.
  5. Qoş düyməsinə basın, brauzer icazə istəyəndə İcazə ver seçin.

Alətlər

  • Zebra — seçilən səviyyədən işıqlı yerlər tünd zolaqla örtülür. Kölgə zebrası çox qaranlıq yerləri göy zolaqla göstərir.
  • False color — parlaqlığı rənglə göstərir. Rənglərin mənası görüntünün altında yazılıb.
  • Focus peaking — fokusda olan kəskin kənarları rəngləyir. Böyütmə ilə fokusu dəqiq yoxlayın.
  • Çərçivə, tor, mərkəz, təhlükəsiz zona — kadr qurmaq üçün xətlər.
  • Desqueeze — anamorfik linza ilə çəkəndə görüntünü düzgün enə açır.
  • LUT — S-Log2/S-Log3 ilə çəkəndə .cube fayl yükləyib normal rəngləri görə bilərsiniz.
  • Histoqram — Stop şkalası parlaqlığı 18% boza nisbətən ekspozisiya stopları ilə göstərir (S-Log-da düzgün deyil).
  • Waveform — şəklin hər sütununun parlaqlığı (0–100%). RGB Parade — eyni şey hər rəng üçün ayrıca, ağ balansını yoxlamaq üçün.
  • Vektorskop — DaVinci Resolve üslubunda: rənglərin istiqaməti və doyğunluğu, dərəcə şkalası, 75% və ya 100% rəng hədəfləri (R, Mg, B, Cy, G, Yl). Narıncı xətt dəri tonu xəttidir: insanların dərisi bu xəttin üstündə olmalıdır. Onu S və ya kartdakı Dəri tonu düyməsi ilə yandırıb-söndürmək olar. 2× az doymuş rəngləri böyüdür, Rəngli iz izi rəngli göstərir.

Bilmək lazım olanlar

  • Alətlər və skoplar kameranın siqnalı ilə (LUT-dan əvvəl) işləyir. Kameranın histoqramı kimi təxmini göstəricidir, RAW deyil.
  • ISO, diafraqma, çəkiliş sürəti və video yazma kameranın özündən idarə olunur — bu səhifə kameranı idarə etmir.
  • Kameranı eyni anda yalnız bir proqram istifadə edə bilər. Imaging Edge Desktop, Zoom, Teams açıqdırsa, bağlayın.
  • Kameranın proqram təminatına heç nə yazılmır, sistem dəyişmir.
